# AXIOM_LAPTOP
Open source laptop design, based off of the Lattepanda Mu, and an MXM formfactor GPU. 14", 2.5K@90Hz OLED Display from Samsung. Features USB-C PD @ 180W (240W hardware capable, WIP)
